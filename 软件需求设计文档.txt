================================================================================
                    电吉他输入控制器 - 软件需求设计文档
================================================================================

版本: v2.0
日期: 2026-08-04
技术栈: WPF + .NET 8 + C# + CommunityToolkit.Mvvm
设计理念: 打开即用，小白友好；高级功能深度可定制

================================================================================
一、项目概述
================================================================================

本软件是一个基于电吉他音频输入的"虚拟输入法"工具。通过音频接口采集电吉他
信号，实时检测音高，并将识别到的音符映射为键盘按键或鼠标操作，从而实现用
电吉他替代/扩展传统键鼠输入。

典型应用场景：
  A. 游戏操控：在 FPS 等游戏中使用吉他代替键盘和鼠标进行操作
  B. 快捷输入：将吉他作为键鼠操作的延伸，实现组合键快捷操作（如 Ctrl+C）

二、核心功能需求
================================================================================

------------------------------------------------------------------------
2.1 音频输入与音高检测
------------------------------------------------------------------------
  [F-01] 支持选择音频输入设备（如声卡、音频接口）
  [F-02] 实时采集电吉他音频信号
  [F-03] 实时检测单音音高（使用科学音高记谱法，如 C4、D4、E4）
  [F-04] 标准音高 A4 默认 = 440Hz，用户可自行调整（如 432Hz、442Hz 等）
  [F-05] 使用科学音高记谱法（Scientific Pitch Notation）显示音高
  [F-06] 暂不支持和弦识别（多音同时）和特殊吉他技法（滑弦、推弦等）

  --- 技术选型（已确定）---
  [F-AUD-01] 音频采集库：NAudio（成熟稳定、社区活跃、LGPL 许可）
  [F-AUD-02] 音高检测算法：YIN 算法（精度高、延迟低）
  [F-AUD-03] 默认采样率：44100Hz
  [F-AUD-04] 缓冲区大小等音频参数预设合理默认值，用户打开即可使用
  [F-AUD-05] 高级音频参数（采样率、缓冲区大小等）放在"高级设置"中，
             供有深度定制需求的用户调整

  --- 音量检测阈值 ---
  [F-AUD-06] 提供用户可自定义的音量检测阈值
  [F-AUD-07] 当音频输入音量低于设定阈值时，不触发输入，视为噪音忽略
  [F-AUD-08] 阈值默认预设一个合理值，用户可在设置中调整

------------------------------------------------------------------------
2.2 音符到键鼠的映射系统
------------------------------------------------------------------------
  [F-07] 提供映射列表界面，用户可自由配置音符与键鼠操作的对应关系
  [F-08] 支持的映射类型：
         a) 单个键盘按键（如 C4 -> W 键）
         b) 鼠标按键（如 G4 -> 鼠标左键、A4 -> 鼠标右键）
         c) 组合键（如 C4 -> Ctrl+C、D4 -> Ctrl+V）
  [F-09] 映射列表支持增、删、改、查操作
  [F-10] 映射方案支持导入/导出（保存为 JSON 配置文件）
  [F-11] 多个映射方案可切换（针对不同游戏或应用场景）

  --- 触发模式（已确定：混合模式）---
  [F-MAP-01] 每个映射条目可独立设置触发模式：
         a) 按住模式：Note On = Key Down，Note Off = Key Up
            （适合游戏 WASD 移动等持续操作）
         b) 脉冲模式：检测到音符立即触发一次按键按下+释放
            （适合组合键快捷操作，如 Ctrl+C）
  [F-MAP-02] 按住模式下，连续拨弦同一音符视为快速连击
             （模拟键盘快速点击，用于游戏中的连续操作）
  [F-MAP-03] 统一映射：不区分弦位置，同音高在不同弦上触发相同映射

  --- 防抖与容错 ---
  [F-MAP-04] 最小音符持续时长：低于此时长的信号视为噪音忽略
             （默认预设一个较低值，放在高级设置中）
  [F-MAP-05] 音高检测置信度阈值：低于此置信度的结果丢弃
             （默认预设合理值，放在高级设置中）
  [F-MAP-06] 连续相同音符去重策略：
         - 可设置"最小输入间隔"，低于此间隔的连续相同音符视为误触/重复
         - 默认间隔值应较低，允许用户快速拨弦实现快速点击
         - 此参数放在高级设置中

------------------------------------------------------------------------
2.3 虚拟吉他指板窗口
------------------------------------------------------------------------
  [F-12] 默认指板规格：标准调音（EADGBE），24 品
  [F-13] 无边框窗口显示
  [F-14] 窗口大小可调整
  [F-15] 支持"置顶显示"（TopMost）开关
  [F-16] 窗口透明度可调节
  [F-17] 实时高亮当前检测到的音高在指板上的所有位置
         （同一音高可能在指板上有多个位置，需全部高亮）
  [F-18] 指板显示/隐藏可切换
  [F-FB-01] 支持鼠标拖拽移动窗口位置
  [F-FB-02] 支持窗口位置锁定功能（锁定后不可拖拽移动）
  [F-FB-03] 支持窗口贴边吸附

------------------------------------------------------------------------
2.4 虚拟键盘窗口
------------------------------------------------------------------------
  [F-19] 提供四种键盘配列供用户选择：
         a) 104 键（标准全键盘）- 默认
         b) 98 键（紧凑布局）
         c) 87 键（无数字区）
         d) 68 键（迷你布局）
  [F-20] 无边框窗口显示
  [F-21] 窗口大小可调整
  [F-22] 支持"置顶显示"（TopMost）开关
  [F-23] 窗口透明度可调节
  [F-24] 实时高亮当前映射触发的按键
  [F-25] 虚拟键盘显示/隐藏可切换

  --- 视觉与交互（已确定）---
  [F-KB-01] 默认未激活状态：按键呈现灰色
  [F-KB-02] 激活状态：按键高亮为白色（参考 Windows 自带虚拟键盘效果）
  [F-KB-03] 按键需要显示文字标签（如 W、Ctrl、Shift 等）
  [F-KB-04] 支持同时高亮显示多个按键（组合键情况）

------------------------------------------------------------------------
2.5 键鼠模拟输出
------------------------------------------------------------------------
  [F-26] 模拟键盘按键按下/释放（Key Down / Key Up）
  [F-27] 模拟鼠标按键（左键、右键、中键）点击
  [F-28] 模拟组合键（带修饰键如 Ctrl、Alt、Shift）
  [F-29] 音符触发策略：混合模式（每映射独立设置，详见 F-MAP-01/02）

  --- 技术选型（已确定）---
  [F-SIM-01] 使用 Windows SendInput API（P/Invoke 直接调用）
  [F-SIM-02] 输入模拟层抽象为接口，支持未来扩展驱动级方案
             以提升对 DirectInput 游戏的兼容性

------------------------------------------------------------------------
2.6 全局热键
------------------------------------------------------------------------
  [F-HK-01] 提供全局热键：一键启用/禁用吉他输入
  [F-HK-02] 提供全局热键：快速切换映射方案
  [F-HK-03] 全局热键可由用户在设置中自定义

------------------------------------------------------------------------
2.7 系统托盘与生命周期
------------------------------------------------------------------------
  [F-TR-01] 支持系统托盘常驻，后台运行
  [F-TR-02] 设置中可自由选择是否开机自启动
  [F-TR-03] 设置中可自由选择是否启动后默认最小化到系统托盘
  [F-TR-04] 系统托盘图标提供右键菜单：显示主窗口、启用/禁用输入、退出等
  [F-TR-05] 关闭主窗口默认最小化到托盘（而非退出程序），可在设置中修改

三、UI 设计规范

------------------------------------------------------------------------
3.1 整体风格
------------------------------------------------------------------------

3.3 高级设置窗口
------------------------------------------------------------------------
  设计原则：将不影响日常使用的复杂参数统一收纳于此。
  通过主窗口底部的"高级设置"按钮进入。

  高级设置包含以下分类：
  ┌─────────────────────────────────────────────┐
  │  [高级设置]                                  │

  │    - 音量检测阈值                             │
  │                                             │
  │  ▸ 音高检测参数                               │
  │    - 最小音符持续时长                         │
  │    - 音高检测置信度阈值                       │
  │    - 最小输入间隔（连续音符去重）               │
  │    - 标准音高 A4 频率                         │
  │                                             │
  │  ▸ 全局热键设置                               │
  │    - 启用/禁用吉他输入                        │
  │    - 切换映射方案                             │
  │                                             │
  │  ▸ 应用行为                                  │
  │    - 开机自启动                               │
  │    - 启动后最小化到托盘                       │
  │    - 关闭窗口时最小化到托盘                   │
  │                                             │
  │  [恢复默认设置]  [保存]  [取消]               │
  └─────────────────────────────────────────────┘

========================================================================
四、非功能性需求
========================================================================

  [NF-01] 低延迟：音频输入到键鼠响应的延迟尽量低（目标 < 50ms）
  [NF-02] 框架：WPF（Windows Presentation Foundation）
  [NF-03] 运行时：.NET 8
  [NF-04] 操作系统：Windows 10 / Windows 11
  [NF-05] 应用程序需支持系统托盘常驻，后台运行
  [NF-06] 架构模式：MVVM（Model-View-ViewModel）
  [NF-07] MVVM 工具库：CommunityToolkit.Mvvm
  [NF-08] 依赖注入：Microsoft.Extensions.DependencyInjection
  [NF-09] 配置文件格式：JSON
  [NF-10] 面向大多数游戏的键鼠模拟兼容性（SendInput 为主，
          预留驱动级方案接口用于未来扩展）

5.4 核心类设计要点
------------------------------------------------------------------------

  5.4.1 依赖注入容器 (AppHost.cs)
    - 使用 Microsoft.Extensions.DependencyInjection
    - 注册所有服务为单例（Singleton）：
      · IAudioCaptureService → AudioCaptureService
      · IPitchDetector → YinPitchDetector
      · IMappingService → MappingService
      · IProfileService → ProfileService
      · ISettingsService → SettingsService
      · IInputSimulator → InputSimulator
    - 注册 ViewModel 为 Transient
    - 通过构造函数注入传递依赖

  5.4.2 音频采集服务 (AudioCaptureService)
    - 封装 NAudio WaveInEvent / WasapiCapture
    - 提供设备枚举方法
    - DataAvailable 事件 → 传入音频缓冲区
    - 可配置采样率、缓冲区大小
    - 提供实时音量电平数据

  5.4.3 YIN 音高检测器 (YinPitchDetector)
    - 实现 IPitchDetector 接口
    - 输入：float[] 音频缓冲区
    - 输出：PitchResult（频率、音名、置信度）
    - 内置音量阈值过滤（低于阈值返回"无音符"）
    - YIN 算法的阈值参数可配置

  5.4.4 映射服务 (MappingService)
    - 维护当前激活的 MappingProfile
    - FindMapping(NoteInfo note) → NoteMapping?
    - 支持按触发模式分类查找
    - 状态追踪：记录当前按住的音符（用于按住模式的 Note Off）

  5.4.5 输入模拟器 (InputSimulator)
    - KeyDown(VirtualKeyCode key)
    - KeyUp(VirtualKeyCode key)
    - KeyPress(VirtualKeyCode key)           // 脉冲模式
    - MouseClick(MouseButton button)
    - SendCombination(ModifierKeys mods, VirtualKeyCode key) // 组合键
    - 注册/注销全局热键

  5.4.6 设置服务 (SettingsService)
    - Load() → AppSettings（从 JSON 文件读取）
    - Save(AppSettings)（写入 JSON 文件）
    - GetDefault() → AppSettings（返回所有默认值）
    - 文件路径：%APPDATA%/GuitarInputController/settings.json

  5.4.7 方案服务 (ProfileService)
    - LoadProfile(string name) → MappingProfile
    - SaveProfile(MappingProfile profile)
    - DeleteProfile(string name)
    - ListProfiles() → List<string>
    - ImportProfile(string filePath) / ExportProfile(string filePath)
    - 文件目录：%APPDATA%/GuitarInputController/profiles/

------------------------------------------------------------------------
5.5 关键技术点
------------------------------------------------------------------------

  5.5.1 音符状态机
    每个已映射的音符维护一个状态：
      Idle → (检测到音符) → Active → (音符消失) → Idle
                            Active → (音符持续) → Active
    按住模式：Active 期间持续发送 Key Down，Idle 时发送 Key Up
    脉冲模式：从 Idle 进入 Active 时发送一次 Key Press
    连续拨弦：Active → 短暂回到 Idle → 再次 Active，视为一次新的
              脉冲触发（当间隔 > 最小输入间隔时）

  5.5.2 延迟优化策略
    - 使用低缓冲区大小（如 256 或 512 samples）
    - YIN 算法使用较小的分析窗口
    - 音频采集与处理在同一管线中，避免不必要的线程切换
    - 音符状态变化立即驱动输入模拟，不做批量处理

  5.5.3 游戏兼容性
    - 主方案：SendInput API（覆盖绝大多数应用和游戏）
    - 扩展预留：IInputSimulator 接口抽象，未来可实现：
      · Interception 驱动方案（需要安装驱动）
      · vJoy 虚拟手柄方案
      · 用户可通过高级设置切换到不同实现

八、风险与注意事项
========================================================================

  1. 游戏兼容性：SendInput 对部分 DirectInput 游戏可能无效，若用户反馈
     较多，需评估引入 Interception 驱动方案的可行性与安全性。

  2. 延迟优化：YIN 算法精度与延迟是权衡关系，默认值保证可用性，
     提供高级设置让高级用户自行调优。

  3. 音高检测准确性：电吉他音色复杂（泛音丰富），在低音区或失真音色下
     可能出现误检，需通过置信度阈值和最小持续时长来过滤。

  4. 用户引导：尽管设计目标是"打开即用"，首次使用仍需引导用户选择音频
     设备和创建基本映射，建议在首次启动时显示简易向导。

  5. 管理员权限：SendInput 通常不需要管理员权限，但若后续引入驱动方案，
     则需要提示用户并说明原因。
